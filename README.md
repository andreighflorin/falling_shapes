# Falling Shapes

A falling shapes playground built with **PIXI.js v8**, **TypeScript**, and **Vite**.

## Overview

Falling Shapes is a browser-based playground for experimenting with falling shapes and interactive graphics, powered by the PIXI.js rendering engine.

The project uses TypeScript for type safety and Vite for a fast development experience and optimized production builds.

## Tech Stack

- **[PIXI.js v8](https://pixijs.com/)** – 2D WebGL/WebGPU rendering engine.
- **[TypeScript](https://www.typescriptlang.org/)** – Typed JavaScript for more reliable development.
- **[Vite](https://vite.dev/)** – Fast frontend build tool and development server.
- **[Node.js](https://nodejs.org/)** – JavaScript runtime.

## Requirements

Before getting started, make sure you have installed:

- Node.js
- npm (included with Node.js)
- Git

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/andreighflorin/falling_shapes.git
```

### 2. Navigate to the project directory

```bash
cd falling_shapes
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will start a local development server. Open the URL displayed in your terminal (usually `http://localhost:5173/`) in your browser.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the local development server. |
| `npm run build` | Runs TypeScript checks and creates a production build. |
| `npm run preview` | Previews the production build locally. |

## Building for Production

To create an optimized production build, run:

```bash
npm run build
```

The generated production files will be available in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
